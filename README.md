# 🏊 42 Piscine

This repository contains the work I completed during the **Piscine at 42 Belgium**, the selection process candidates go through before they can join the 42 curriculum.

> ⚠️ The code is kept **exactly as I wrote it at the time**, on purpose.
> It is a snapshot of where I started, and shows how far I've come since.

## What is the Piscine?

The Piscine ("swimming pool" in French) is an intensive selection bootcamp of about **4 weeks**, full-time.
Candidates start programming **from zero**, with no prior experience required, and are thrown into the deep end:

- 🧠 **Learning by doing**: no teachers, no lectures. Only the subjects, the documentation, and your peers.
- 🔁 **Step-by-step progression**: each project has to be validated, and its exercises understood, before moving on to the next one.
- 🤝 **Peer-to-peer evaluation**: every project is reviewed and graded by other candidates, and checked by an automated grading system (Moulinette).
- 📝 **Weekly exams**: timed exams in a restricted environment, without internet access.
- 👥 **Rushes**: short weekend group projects, with teammates assigned at random.

It tests more than technical skill: **autonomy, resilience, adaptability, and the ability to absorb new concepts quickly.**
